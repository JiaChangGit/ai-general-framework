# 2026-11-09 小型有／無框架對照

這次文字層對照沒有觀察到框架組的正確性、可觀察邊界或返工優勢；框架組合計多用 17,781 個實際 token，約 14.4%。這是同一模型、每項一次的小樣本，不能推成框架普遍無效，也不能拿來宣稱省 token。原定的工具式試驗受宿主阻擋，因此本次只比較已提供指引的效果，沒有驗證技能發現、選讀效率或模型自主執行除錯。

## 相同條件與唯一介入

固定 Windows Codex CLI `0.167.0-alpha.3.2`、指定 `gpt-6.1-sol`、`medium` reasoning；兩組共用原生宿主指示及可見的系統／plugin 技能清單，未發現全域 AGF 五個技能。Provider 沒有回報實際權重版本，記錄的是指定模型別名。框架固定在 `ffa02b1`，避免同時進行的 hook／教學修改改變試驗條件。

兩組收到相同任務、原始碼、日誌及明確的無工具限制；框架組額外收到該版本的專案規則、預設偏好，以及對應的 trace／debug skill 或 writing／workflow 指引。指引是直接放進提示，並非觀察原生宿主自動載入。原始材料逐 SHA-256 核對一致；交接接手階段只允許前一階段各自產出的兩份文件不同。

每項各一對；trace、debug、改寫各兩次，交接各有產生與全新對話接手兩階段，共 10 個不同 thread。執行順序為 trace 無／有、debug 有／無、改寫無／有、交接有／無，沒有補正提示或挑選重跑。交接期間兩組設定都從 TTL 30 改成 20；消費者收到的是自己那組產出的交接與記憶，沒有前一段聊天歷史。

## 先看成果

獨立代理在看到答案前建立判準，之後只取得匿名 A／B 產物與原始材料，未取得組別對照或用量。產物本身可能透露指引痕跡，這不是完整雙盲。判準分為正確性 4 分、證據與不確定性 2 分、可觀察邊界 2 分；不以字數或固定措辭評分。

| 項目 | 無框架 | 有框架 | 實際觀察 |
|---|---:|---:|---|
| Trace | 8／8 | 8／8 | 都找對 r42 的拒絕分支、狀態與來源位置，分清 log 與程式推論 |
| Debug | 8／8 | 8／8 | 都指出 busy 前寫入識別碼的副作用，產出相同的最小修法 |
| 中文改寫 | 8／8 | 8／8 | 都保留否定、2 秒、一次、規範強度、未知及局部修字範圍 |
| 交接產生 | 8／8 | 8／8 | 都保留來源、驗證狀態、理由與操作範圍，沒有把單次偏好或假說當永久記憶 |
| 全新對話接手 | 8／8 | 8／8 | 都算出目前到期時間 120、125 秒時無效，辨認舊驗證與固定斷言已過期 |

兩組皆無可觀察的越界產物、工具呼叫或需要外部補正的返工；這不代表有工具時也不會越界。模型都明說自己沒有執行測試。評分者另在隔離目錄執行原始與修正版重現、兩份各四項回歸，以及事先保留的語意驗收；修正版與隱藏驗收皆通過。原始程式的兩項失敗是成功重現問題，沒有計成返工。交接的舊／新設定也由評分者實跑，分別得到 `130/True`、exit 0 與 `120/False`、exit 1；沒有把測試者的執行冒充模型執行。

## 沒有藏掉的設定失敗與限制

起初只驗證 CLI 能回文字，沒有先確認工具可執行，這項試跑不足。原生工具式試驗中，唯讀命令被政策拒絕，五個已完成呼叫未讀到來源；另有一個呼叫中止。之後單次工具預檢仍回報 `registered Core launch requires an installed app`，沒有繞過 sandbox 或更動全域設定。

這些失敗、最初的文字試跑及單次工具預檢另列為 CLI 設定成本：已知 input 548,250（其中 cached 443,392）、output 2,209；中止呼叫的用量未知。它們沒有混入上方能力對照，也沒有因 exit 0 就算任務成功。主對話與評分代理的 usage 未提供，所以整次開發的總用量仍未知。
