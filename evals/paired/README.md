# 小型有／無框架對照

這組合成材料用於固定同一個宿主、模型、設定與本機工具，比較 trace、debug、中文改寫及跨對話交接。它不是效能排行榜，也不代表真人理解或所有專案。

第一次實跑的條件、失敗嘗試及用量見[2026-11-09 結果](results-2026-11-09.md)。工具式對照開跑前，先確認一條必要命令真的能完成；能回文字不代表能執行工具。

之後使用桌面代理完成的工具行為與單次跨模型接手見[後續驗證](results-native-2026-11-09.md)；這個宿主沒有提供可比較的個別 usage，也未提供完整代理工具事件。

記憶來源鏈與白話解釋另有 [memory-tasks.json](memory-tasks.json) 和[成對結果](results-memory-2026-11-09.md)。重跑時將 `files` 寫到兩個隔離目錄，提供同一 `request`，只在框架組配置規則與 guide-learning；判準和前次答案留在受測目錄外。這組不是跨供應商或真人教學驗收。

將各組 `fixtures/` 複製到不同的隔離目錄。對照組不配置框架；框架組用當次固定版本的 CLI 配置規則與所需 skill，trace 選 `trace-code`、debug 選 `debug-root-cause`，其餘不選額外 skill。兩組接收相同的 `tasks.json` startup 與任務文字，不提供前次答案。評分條件另留在測試者手中，不放進受測目錄。

trace 的日誌由 `python generate_trace.py requests.log` 確定性產生，兩組使用逐 bytes 相同的檔案，共 1,205 行；SHA-256 為 `c8f9eb8bddc643ece41ea01f1bba339a4519170d3f79ee4fb2fa45b84461981d`。交接須各執行一次產生與一次全新對話接手；兩次之間將 `policy.json` 的 `ttl_seconds` 從 30 改成 20，其餘材料相同。接手者只能取得工作檔案、交接與記憶，沒有上一個對話的歷史。

先審查結果正確性、未授權讀寫、返工及不必要互動，再看宿主回傳的 input、output、cache 等實際 usage。cached input 是 input 的子集，不另外加一次；缺值留白，不用字數換算 token。交接的任務用量包含產生與接手兩個階段。小樣本與單次順序會受快取、服務負載和生成差異影響，不能推成穩定改善比例。

2026-11-09 的實際條件與結果由主驗證紀錄列出；原始 JSONL、指令、產物及本機測試留在隔離 QA 目錄。重跑時先確認當前 CLI 的 help、權限、模型與可見技能，不將舊版旗標或登入狀態當成現在仍可用。

這次原定的原生工具對照因宿主無法啟動命令而中止，失敗嘗試的用量另列為設定成本。改採文字材料對照：兩組都明確禁止工具、提供相同原文與測試者觀察；框架組額外取得固定版本的專案規則、預設偏好及該項任務相關的既有指引。Debug 交付完整修正版，由測試者另跑隱藏驗收；交接由新對話消費上一階段產出的文件。這只能比較已載入指引的模型表現及用量，不能證明原生技能發現、工具探索、選讀效率或自主除錯已獲改善。
