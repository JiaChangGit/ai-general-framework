# 語意與閱讀校閱

先讀整段的目的，再改語句，不只逐個替換被標記的詞。

| 待修句 | 問題 | 改寫方向 |
|---|---|---|
| 透過優化機制顯著提升效能與穩健性。 | 看不出改了什麼，也沒有改善數據 | 說明實際減少的工作或處理的失敗條件；沒有測量就不宣稱顯著改善 |
| 這不是單純的佇列，而是可靠性的基石。 | 沒有增加對機制的理解 | 說明工作何時入列、拒絕時保留什麼狀態，以及由誰重試 |
| 此時它會更新該欄位，因此完成。 | 角色、欄位和完成條件不明 | 明示元件與欄位，分開描述狀態更新和完成通知 |

朗讀或重新逐句閱讀，核對代詞、話題轉換、因果和語氣。適度斷句，但不限制固定句長或每段句數。繁體轉換不能代替台灣用語與上下文校閱；API、symbol、命令與正式名稱保留精確形式。

讓未看過聊天的人檢查：能否找到問題、關鍵前提、理由、限制與下一步？領域熟悉者再核對技術內容。兩種檢查回答不同問題；都不能替代真人使用回饋。
