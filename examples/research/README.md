# 論文與規格閱讀情境

這些範例練習定位來源、保留條件及區分主張與證據。它們不要求下載私人 PDF，也不使用 AI 作答分數判斷真人是否學會。

- [小規格](mini-spec.md)：自製的教學文件，刻意限定在同步、記憶體內的批次入列。
- [規格帶讀](spec-reading.md)：沿一個輸入查條文，再與 [Python 程式](../learning/queue_walkthrough.py) 對照。規格支持的行為不等於程式已符合它。
- [論文閱讀](paper-reading.md)：以公開閱讀指南示範如何分辨作者方法、證據與可推廣範圍。

先說明這次目的：理解、比較、實作還是重現。只有在需要時才深入下一層，不把每篇文件都變成固定長度的摘要或考卷。
