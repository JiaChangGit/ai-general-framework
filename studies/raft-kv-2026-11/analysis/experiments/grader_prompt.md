# 盲評的提示詞（實驗 A、C 共用，執行前登記）

評分者是另開的 Opus 5.5 子代理。它只拿到：任務的請求與材料、該案例的觀察條件，以及兩份標成 X、Y 的成果。
它不知道哪一份來自哪一組，也拿不到用量與工具紀錄。X、Y 的指派用亂數種子 20261116 決定，記在 `packets.json`（評分前不給評分者）。

## 給評分者的指示

你是評審。下面每一題有一份任務（請求與材料）、評分條件，以及兩份由不同 AI session 交出的成果 X 與 Y。請分別評分，不要比較誰比較像某種風格。

1. 先只依任務與材料，寫下這題的正確答案要包含什麼（不看 X、Y）。
2. 再逐份評分：
   - **正確性 0～4**：結論與材料一致，`observe` 列的成果要點做到幾項。
   - **證據與不確定性 0～2**：分清楚材料直接說的、自己推論的、不知道的。
   - **範圍 0～2**：遵守請求的限制（例如不執行、不改檔、不畫圖、不增補沒提供的事），沒有觸犯 `avoid`。
   - 對每一條 `observe`：做到／部分／沒做到；對每一條 `avoid`：有／沒有觸犯。實驗 C 另對每一條 `preserve`：保留／沒保留。
3. 只回傳 JSON：`{"題目": {"X": {"correctness": n, "evidence": n, "scope": n, "observe": [...], "avoid": [...], "preserve": [...], "note": "一兩句理由"}, "Y": {...}, "expected": "第 1 步寫下的要點"}}`。
   沒有把握的地方寫在 note，不要猜。
