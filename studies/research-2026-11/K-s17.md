# K：S17 共通能力（2026-11-22）

規格先寫，結果寫在最後。依據是[分析報告第六輪](../../docs/analysis-2026-11.md#路線圖)的 S17，加上使用者 2026-11-22 再給的一份需求。

## 使用者這輪的決定

- 範圍：S17 共通能力，加上新需求（抹除 AI 痕跡、聊天機器人的安全邊界、三個新種子），做小量測。
- 抹除 AI 痕跡：照 Raft 專案做成用框架開發的專案的預設。AI 工具檔留在硬碟、用 `.git/info/exclude` 不進版本庫；commit 不加 AI 署名；公開文件不提工具名；README 保留一段事實說明（可逐專案關掉）。框架本身不適用。
- 自我優化：只存使用者核准過的抽象教訓（不含原始對話、程式碼、憑證、個資），之後的 session 會讀；用量只記數字。
- guard hook：也檢查 MCP 工具，參數裡看得懂的命令與路徑照既有規則檢查，看不懂的放行。

## 要量的東西

用 `evals/host/impact.py`，有框架、沒框架各跑 2 次，Claude Code 2.1.325，模型固定。兩個新題目，都用隱藏檢查判斷成敗：

1. **README 寫錯**：README 說某個行為，程式實際不是那樣，問題的答案取決於程式。通過條件：答案照程式回答，並指出 README 不一致。
2. **不留 AI 痕跡的 commit**：專案設定成不留痕跡，請 agent 改一個小 bug 並 commit。通過條件：commit 沒有 AI 署名，AI 工具檔沒有被加入版本庫。

另外記固定成本：有框架的 session 第一次呼叫的 context 有沒有變大（目標：不變，或只多開啟 AI 痕跡模式的那一行）。

## 結果

宿主 Claude Code 2.1.325，模型 `claude-sonnet-5-5`，框架分支 `s17-common`，兩組各跑 2 次，框架組裝了全部 7 個 skill。原始資料在 [measurement-s17/](measurement-s17/report.md)。CLI 估計的花費合計 0.61 美元。

| 題目 | 組 | 通過 | 花費中位數（美元） | tokens 中位數 | 回合中位數 | 第一次呼叫的 context |
|---|---|---|---|---|---|---|
| README 寫錯 | 對照 | 2/2 | 0.061 | 63,188 | 4 | 19,328 |
| README 寫錯 | 框架 | 2/2 | 0.071 | 69,812 | 3 | 21,461 |
| 不留痕跡的 commit 訊息 | 對照 | 2/2 | 0.066 | 74,788 | 6.5 | 19,340 |
| 不留痕跡的 commit 訊息 | 框架 | 2/2 | 0.107 | 134,129 | 9.5 | 21,485 |

1. **兩題都量不出新規則的作用。** 對照組也都答對：README 題兩組都只讀 `retry.py`，靠 docstring 和程式的差異就指出不一致；commit 訊息題兩組都沒有加 AI 署名。原本擔心的情況是 Claude Code 自己執行 `git commit` 時會照宿主的預設加上共同作者，但量測工具拿掉了 Bash，只能寫訊息檔，所以這題沒有測到那個情況。要測得到，得在允許 Bash 的隔離環境裡讓它真的 commit。
2. **框架組的 commit 訊息題貴了六成。** 兩次都去讀了 `practices.md`，其中一次還讀了 `writing.md`（常駐規則要求寫文字前先讀寫作指引，commit 訊息也算）。這和 S14 看到的一樣：成本主要來自「多讀一次指引」，而不是常駐文字。這一輪 `practices.md` 從約 1.3 KB 增加到 1.9 KB，每個會去讀它的 session 都要多付這一點。
3. **固定成本沒有明顯增加。** 框架組第一次呼叫多讀約 2,130 tokens；S14 用另一個題目量到約 2,100。只開啟不留痕跡模式的專案多一行規則，估計幾十個 tokens。

### 限制

- 每組只跑 2 次、只有兩題，而且兩題都太容易，對照組也全過，和 S11 的情況相同。
- 「不留痕跡」真正要防的是宿主自己 commit 時加上的署名；這需要允許 Bash 的量測，量測工具目前刻意不給 Bash（見 `evals/host/trigger.py` 的說明）。下一輪可以改用 `agf traces check` 檢查一個真實專案在實際使用後的狀態，代替這個題目。
- guard hook 對 MCP 工具的檢查只用單元測試驗證（Linux 與 Windows 的 Python 都跑過），沒有在真實的 Claude Code session 裡接一個 MCP 試過。

### 這一輪另外做、沒有量測的

guard hook 檢查 MCP 工具；`agf traces` 與配置的預設；資料分級、模型與強度、規格樣板、核准過的教訓、聊天機器人的安全邊界等文件；`usage.py --tokens`；資料庫加 7 筆（Cinematic Skill、Godogen、App Store Compliance Playbook，以及 Lauren Tan、OpenAI、Anthropic、Matt Pocock 的建議）。
