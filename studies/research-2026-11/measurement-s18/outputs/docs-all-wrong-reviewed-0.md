我核對過了，結論不變：`parse_duration("1h30m")` 回傳 **5400**，單位是**秒**。`answer.json` 的內容 `{"value": 5400, "unit": "seconds"}` 是正確的，所以我沒有改動任何檔案。

**我讀到的內容：**
- `duration.py:4` 的換算表是 `{"h": 3600, "m": 60, "s": 1}`。
- `duration.py:10` 用正規表示式 `(\d+)([hms])` 拆字串，`"1h30m"` 會拆成 `("1","h")` 和 `("30","m")`。加總是 1×3600 + 30×60 = 5400。
- `test_duration.py` 的預期值也是秒：`"2m"` 對應 120，`"1h"` 對應 3600。不過兩個測試的名稱寫的是 minutes（`test_returns_minutes`、`test_hours_in_minutes`），和實際的斷言對不上。

**和程式行為不符的文件：**
- `README.md:3` 說回傳分鐘數，並舉例 `"1h30m"` 回傳 90。
- `duration.py:1` 模組 docstring 和 `:8` 函式 docstring 也說回傳分鐘數，並舉例 `"2m" -> 2`。

設定逾時的時候請把回傳值當成秒。如果照 README 當成分鐘，實際的逾時會是你預期的 60 倍。
