**有一件事要你決定**

README 規定輸入是「非負整數」，但目前遇到小數不會報錯，而是直接捨去。例如 `3599.9` 會得到 `0:59:59`，呼叫的程式傳錯值也不會察覺。

- **維持現狀**：比較寬鬆，但有錯的輸入會被悄悄接受。
- **改成拒絕非整數**：小數也拋出 `TypeError`，比較貼近 README 的字面意思，但原本傳小數的呼叫會開始報錯。

我建議改成拒絕非整數，不過 README 沒有明確禁止小數，所以我沒有自己改。你決定要改的話，只需要在函式開頭多加一個型別檢查。
