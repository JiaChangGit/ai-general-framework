# 讓帶讀對準這次想學會的事

先從對話與材料理解想完成什麼、已知道什麼與卡在哪裡；只有未知事項會改變教法時才問。已有答案或資訊足夠時就直接帶讀，不讓使用者先填問卷、選學習法或重複說明背景。

五個自動入口以目的分界：`trace-code` 解釋具體操作的程式路徑；`debug-root-cause` 調查已觀察的異常；`review-change` 審查指定程式差異；`read-research` 判讀或帶讀指定論文／spec；`guide-learning` 教 repo、工程概念與工具。指定 spec 的帶讀不再疊加通用教學入口，純擷取或轉檔也不啟動閱讀 skill。一般開發與創作使用宿主能力。

初次操作時可示範一個完整小情境；概念問題就回答關鍵關係。依互動逐漸減少提示，再視需要加入預測、解釋理由、比較相近情境或後續重用。這些方法是可選工具，不是固定題數或每次必跑的順序。直接帶讀時完整提供解說，不以答題阻擋進度。

來源解釋、教學假設、實際執行與使用者的理解分開。圖上的箭頭對應真實呼叫、事件、資料或通知，單次 backtrace 不代表完整非同步歷史。教材、腳本或 AI 答案通過，只能支持相應檢查；真人是否能說明理由、完成相近任務或長期記住，仍需要真實觀察。

Linux kernel／Boost 可由一個行為、模組或測試建立理解，再接一項可驗證的小貢獻。FreeRTOS／STM32 帶讀需對應實際板子與 port；host、模擬器及 build 結果不等於實板結果。需要時才查官方規則，操作分工見 [delivery.md](delivery.md)。股票分析程式可追蹤資料來源、轉換與計算；不把數值結果自動當成採用結論或券商操作授權。

可直接用 [佇列案例](../examples/learning/README.md) 練習靜態追蹤、執行對照與原子性故障；用 [研究閱讀案例](../examples/research/README.md) 核對條件、主張和證據。這些是可重跑教材，不是使用者已學會的證明。

學習方法與限制保存在 [按需方法參考](../skills/guide-learning/references/methods.md)，來源採用理由見 [research.md](research.md)。日常協作與白話提問見 [workflow.md](workflow.md)，不另建立教學總管。
